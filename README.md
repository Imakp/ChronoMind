# ChronoMind

> A year-based personal knowledge management system with intelligent cross-referencing through highlights and tags

ChronoMind is a modern web application designed to help you organize your thoughts, goals, and insights chronologically while maintaining powerful connections across time through a global tagging system. Built for individuals who value structured reflection and knowledge synthesis.

## 🧩 Description

ChronoMind transforms how you capture and connect your personal knowledge by organizing content into yearly containers with six specialized sections. Unlike traditional note-taking apps, ChronoMind emphasizes temporal organization while enabling cross-year discovery through its highlight-to-tag feature.

The application automatically creates daily log entries, tracks hierarchical goal progress, organizes reading notes, and provides dedicated spaces for lessons learned and creative ideas. Every piece of content can be highlighted and tagged, creating a web of connections that reveals patterns in your thinking across months and years.

## ⚙️ Features

### Year-Based Organization

- Create and manage separate yearly containers for your content
- Navigate seamlessly between different years
- Automatic initialization of all six sections when creating a new year

### Six Specialized Sections

ChronoMind organizes your personal knowledge into six distinct sections, each designed for specific types of content and thinking patterns. This structure helps maintain clarity while enabling powerful cross-connections through the global tagging system.

#### 📅 Daily Logs

_Your chronological thought stream_

**Purpose**: Capture daily thoughts, activities, observations, and experiences in a structured timeline format.

**Key Features**:

- Automatic creation of daily entries with date stamps
- Chronological view of your daily thoughts and activities
- Rich text editing with full formatting support
- Auto-save functionality to preserve your entries

**Use Cases**:

- **Daily Journaling**: Record personal reflections, mood, and significant events
- **Work Log**: Track daily accomplishments, challenges, and decisions
- **Learning Notes**: Capture insights from meetings, conversations, or research
- **Habit Tracking**: Document progress on personal habits and routines
- **Memory Preservation**: Create a searchable archive of your daily experiences
- **Problem Solving**: Work through challenges by writing them out day by day

**Best Practices**:

- Write consistently, even if just a few sentences
- Use highlights and tags to mark important insights for future reference
- Include both professional and personal content for a complete picture
- Review previous entries to identify patterns and growth

#### 🔄 Quarterly Reflections

_Deep thinking and strategic review_

**Purpose**: Provide dedicated space for longer-form reflection and strategic thinking at quarterly intervals.

**Key Features**:

- Four dedicated long-form editors (Q1, Q2, Q3, Q4)
- Perfect for deeper insights and periodic reviews
- Auto-save functionality to preserve your reflections
- Rich text formatting for structured thinking

**Use Cases**:

- **Strategic Planning**: Set and review quarterly objectives and priorities
- **Performance Review**: Analyze achievements, failures, and lessons learned
- **Life Assessment**: Reflect on personal growth, relationships, and life direction
- **Career Development**: Evaluate professional progress and plan next steps
- **Project Retrospectives**: Conduct thorough reviews of major projects or initiatives
- **Seasonal Planning**: Align activities with natural cycles and energy levels
- **Goal Adjustment**: Refine yearly goals based on quarterly learnings

**Best Practices**:

- Schedule dedicated time for each quarterly reflection
- Review your daily logs and other sections before writing
- Ask yourself structured questions about progress, challenges, and insights
- Use tags to connect themes across different quarters and years

#### 🎯 Yearly Goals

_Hierarchical goal management with progress tracking_

**Purpose**: Organize and track your aspirations using a structured three-level hierarchy with automatic progress calculation.

**Key Features**:

- Three-level hierarchy: Goals → Tasks → Sub-tasks
- Automatic percentage calculation that rolls up from sub-tasks
- Visual progress tracking at every level
- Expandable/collapsible navigation for easy management

**Use Cases**:

- **Personal Development**: Track learning goals, skill development, and habit formation
- **Career Advancement**: Manage professional objectives and milestone achievements
- **Health & Fitness**: Monitor wellness goals, exercise routines, and health metrics
- **Financial Planning**: Track savings goals, investment targets, and budget objectives
- **Creative Projects**: Manage artistic endeavors, writing projects, or creative challenges
- **Relationship Goals**: Nurture personal relationships and social connections
- **Travel & Experiences**: Plan and track experiential goals and adventures

**Best Practices**:

- Break large goals into specific, actionable tasks and sub-tasks
- Set realistic timelines and regularly update progress
- Use the percentage tracking to maintain motivation
- Tag related content from other sections to create goal-supporting resources

**Purpose**: Organize insights and knowledge from your reading using a three-tier hierarchical system.

**Key Features**:

- Three-tier organization: Genre → Book → Chapter
- Structured approach to capturing reading insights
- Expandable/collapsible navigation for easy browsing
- Rich text editing for detailed note-taking

**Use Cases**:

- **Academic Research**: Organize scholarly reading by subject and source
- **Professional Development**: Capture insights from business and industry books
- **Personal Growth**: Document lessons from self-help and philosophy books
- **Fiction Analysis**: Record thoughts on characters, themes, and literary techniques
- **Reference Building**: Create a searchable database of key concepts and quotes
- **Book Recommendations**: Track books to read and maintain reading lists
- **Knowledge Synthesis**: Connect ideas across different books and authors

**Best Practices**:

- Create genres that align with your interests and goals
- Write chapter notes immediately after reading for better retention
- Use highlights and tags to mark key concepts for cross-referencing
- Include both direct quotes and your personal interpretations

#### 💡 Lessons Learned

**Purpose**: Collect and organize individual insights, lessons, and wisdom gained from various experiences.

**Key Features**:

_Unstructured space for spontaneous ideas_

**Key Features**:

**Use Cases**:

### 🏷️ Global Tagging System

_Intelligent cross-referencing and knowledge discovery_

**Purpose**: Create a powerful web of connections across all your content, enabling you to discover patterns, themes, and relationships that span different sections, years, and contexts.

**Core Functionality**:

- **Universal Highlighting**: Select and highlight any text in any section across all years
- **Multi-Tag Assignment**: Assign multiple tags to a single highlight for rich categorization
- **Tag Explorer**: Dedicated interface to browse all tags and their associated content
- **Cross-Reference Discovery**: Find related content across different sections and time periods
- **Visual Indicators**: Highlighted text is visually distinct with tag information on hover
- **Contextual Navigation**: Jump directly from tag explorer to the original content location

**How It Works**:

1. **Text Selection**: Simply select any text in any editor (Daily Logs, Goals, Book Notes, etc.)
2. **Tag Assignment**: A tagging interface appears allowing you to type tag names
3. **Multiple Tags**: Use comma-separated values to assign multiple tags to one highlight
4. **Instant Saving**: Tags are automatically saved and the text becomes visually highlighted
5. **Global Access**: All tagged content becomes searchable through the Tag Explorer

**Advanced Features**:

- **Hierarchical Tags**: Use formats like "productivity/time-management" for organized tag structures
- **Tag Autocomplete**: Previously used tags are suggested as you type
- **Bulk Operations**: View and manage all highlights for a specific tag
- **Export Capabilities**: Extract all content for specific tags across your entire knowledge base
- **Timeline View**: See how your thinking on specific topics evolved over time

**Use Cases & Applications**:

**📊 Pattern Recognition**:

- Tag recurring themes to identify patterns in your thinking
- Track how your perspective on topics changes over months and years
- Discover unexpected connections between seemingly unrelated content

**🔍 Research & Learning**:

- Tag concepts while reading books and reference them in daily logs
- Create thematic collections of insights across different sources
- Build comprehensive knowledge maps on specific subjects

**🎯 Goal Alignment**:

- Tag content related to specific goals to see supporting insights
- Connect lessons learned to current objectives
- Track progress themes across different time periods

**💼 Professional Development**:

- Tag career-related insights for performance reviews
- Collect leadership lessons from various experiences
- Build expertise maps in specific skill areas

**🧠 Personal Growth**:

- Tag emotional insights and relationship patterns
- Track personal development themes and breakthroughs
- Connect philosophical insights across different life experiences

**📈 Project Management**:

- Tag project-related content across all sections
- Connect project lessons to future planning
- Build institutional knowledge for recurring project types

**Best Practices**:

**Tag Naming Conventions**:

- Use consistent, descriptive tag names
- Consider hierarchical structures (e.g., "health/nutrition", "health/exercise")
- Keep tags specific enough to be useful but broad enough to recur

**Strategic Tagging**:

- Tag content immediately while context is fresh
- Don't over-tag - focus on truly significant concepts
- Review and refine your tag system periodically

**Discovery Workflows**:

- Regularly browse the Tag Explorer to rediscover forgotten insights
- Use tags to prepare for quarterly reflections and goal planning
- Create tag-based reports for specific projects or decisions

**Cross-Temporal Analysis**:

- Compare how your thinking on topics has evolved
- Use tags to create longitudinal studies of your personal development
- Identify recurring challenges and successful solution patterns

The Global Tagging System transforms ChronoMind from a simple note-taking app into an intelligent knowledge management system that grows more valuable over time as connections multiply and patterns emerge.

## 🚀 Installation & Setup

### Prerequisites

- Node.js 20.x or higher
- PostgreSQL database (or Neon serverless PostgreSQL)
- npm or yarn package manager

### Environment Variables

Create a `.env` file in the root directory:

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/chronomind"

# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-key-here"

# Optional: OAuth providers
# GOOGLE_CLIENT_ID="your-google-client-id"
# GOOGLE_CLIENT_SECRET="your-google-client-secret"
```

### Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/Imakp/chronomind.git
cd chronomind
```

2. Install dependencies:

```bash
npm install
```

3. Set up the database:

```bash
# Generate Prisma client
npm run db:generate

# Push schema to database
npm run db:push

# Optional: Seed with sample data
npm run db:seed
```

4. Run the development server:

```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

### Production Build

```bash
npm run build
npm start
```

## 🧠 Usage

### Getting Started

1. **Sign Up/Sign In**: Create an account or sign in with your credentials
2. **Create Your First Year**: Click on the year selector and create a new year container
3. **Explore Sections**: Navigate through the six sections using the dashboard
4. **Start Writing**: Begin capturing content in any section with auto-save enabled

### Highlighting and Tagging

1. Select any text in any editor
2. A tagging menu will appear
3. Type tag names (comma-separated for multiple tags)
4. Press Enter to save
5. Tagged text will be visually highlighted

### Exploring Tags

1. Navigate to the Tags section
2. Browse all available tags
3. Click on any tag to see all associated content
4. View source information (year, section, date) for each highlight

### Managing Goals

1. Create a goal with a title
2. Add tasks under the goal
3. Add sub-tasks under each task
4. Check off sub-tasks as you complete them
5. Watch percentages automatically update up the hierarchy

### Organizing Book Notes

1. Create a genre (e.g., "Science Fiction", "Business")
2. Add books under the genre
3. Create chapters for each book
4. Write your notes in the chapter editor
